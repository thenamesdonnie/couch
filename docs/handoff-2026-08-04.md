  (InputPlumber evaluated seriously and declined WITH receipts: root

## 4. Legacy bugs found tonight (NOT fixed — your call)

Pre-declared as expected diffs (T3) so the shadow doesn't hide them:
- **(a)** Pure Big Picture PS-holds never write /tmp/game-suspended, so
  ~10s later reconcile takes the pad off Kodi — pad routed to nobody.
- **(b)** Games launched FROM Big Picture record appid as the literal
  string "bigpicture"; that game's Kodi tile then CLOSES it instead of
  resuming. (PS tap and phone resume still work.)
- **(c)** pad-connect-daemon + tv-waker "any js*" checks (section 0's
  root cause) — also means ANY virtual joystick (vpad rigs, Sunshine)
  silently breaks pad reconnect + TV wake.
- **(d)** guard's pidfile isn't removed on normal exit (leak flagged by
  couchd's invariant every tick).
- Three `steam_app_*` class predicates are fragile identity assumptions
  (guard:272, screen.js:271+291) — dissolve naturally as couchd absorbs
  those responsibilities; fix earlier only if gamescope ever un-parks.

Say the word and I'll fix any of these in the old stack (small, but
they're behavioral changes to live console plumbing, so your call).
