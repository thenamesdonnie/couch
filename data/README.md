# data/

Working directories for the reverse-engineering and modding work in `tools/`. What is here is the
**analysis**: findings, disassembly notes, generator scripts and patches.

**Game files are deliberately not included.** Anything extracted from a retail game — parameter
bundles, script bytecode, sound archives, command tables lifted from an executable — belongs to its
publisher and is not redistributable, so it is excluded from this repository. The tools expect you
to supply your own copy; each directory's findings document says what it needs and where it goes.
